# 本地化——简体中文（`zh-Hans`）

通用规则见[本地化](localizacao.md)。

- **代码：** `zh-Hans`，绝不用 `zh-CN`（Docusaurus 主题只带
  `zh-Hans`）。浏览器的 `zh`、`zh-CN` 和 `zh-SG` 都解析到它；繁体中文
  （`zh-TW`、`zh-Hant`）回落到 pt-BR。
- **复数：** 只有 `other`——pt-BR 的复数键变成一种形式。
- **术语：** 在 pt-BR 中保留英文的术语表词条（*handoff*、*gate*、*runner*）
  在这里同样保留英文。正文使用全角标点，代码内绝不使用。
- **不翻译：** Brabo、agent 名称和角色名称、命令、路径、RN/ADR 编号。
