Creates a PENDING pull request — nothing downloads yet

POST 
/workspaces/:workspaceId/huggingface/pull-requests

First of two explicit steps: this call only records the intent, in pending_confirmation. Nothing is pulled until a separate call to POST .../pull-requests/:id/confirm — the product never runs an automatic, silent pull.

Request​

Responses​

  • 201
  • 400
  • 401
  • 403
  • 429

Invalid body. The ValidationPipe runs with whitelist and forbidNonWhitelisted, so an unknown field also fails.

No token, expired token, or invalid signature.

Requires maintainer on the workspace.

Rate limit per user or per IP.
