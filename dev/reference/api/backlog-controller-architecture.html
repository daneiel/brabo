Devolve o module_map vigente, as ADRs e as pendências

GET 
/projects/:projectId/architecture

O mapa vigente é o de maior version (o histórico é imutável). As pendências são a validação cruzada história↔mapa: história sem módulo, ou apontando um módulo que não existe.

Request​

Responses​

  • 200
  • 401
  • 403
  • 404
  • 429

Sem token, token expirado ou assinatura inválida.

Papel insuficiente no projeto.

Projeto inexistente.

Rate limit por usuário ou por IP.
