# Локализация — упрощённый китайский (`zh-Hans`)

Общие правила — в [Локализации](localizacao.md).

- **Код:** `zh-Hans`, никогда `zh-CN` (тема Docusaurus поставляется только с
  `zh-Hans`). `zh`, `zh-CN` и `zh-SG` браузера разрешаются в него; традиционный
  китайский (`zh-TW`, `zh-Hant`) попадает в pt-BR.
- **Множественное число:** только `other` — ключ множественного числа из pt-BR становится одной формой.
- **Терминология:** термины глоссария, которые остаются на английском в pt-BR
  (*handoff*, *gate*, *runner*), остаются на английском и здесь. Полноширинная
  пунктуация в обычном тексте, никогда внутри кода.
- **Не переводится:** Brabo, имена агентов и ролей, команды, пути,
  номера RN/ADR.
