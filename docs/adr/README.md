# Architecture Decision Records

Convenção estabelecida nesta sessão (não havia nenhuma anterior):

- Um arquivo por decisão: `docs/adr/NNNN-titulo-curto.md`, numeração
  sequencial de 4 dígitos, sem reuso mesmo se um ADR for superado.
- Seções: **Contexto** (o problema/força que motivou a decisão),
  **Decisão** (o que foi decidido), **Consequências** (trade-offs
  aceitos, o que fica pra depois).
- Sem template de terceiros (Nygard/MADR/etc.) — só essas 3 seções.
- Um ADR superado por decisão posterior não é editado; o novo ADR
  referencia o antigo e explica o que mudou.
