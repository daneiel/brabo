    视觉审计：Rodada 29 之前与之后

    AT-290（EP-031，HS-074）。这是一次测量，而不是变更：为了写这一页，apps/ 中没有任何改动。“之前”的截图于 2026-09-30 针对 dev 的 de18e6a6e2 进行； “之后”的截图于同一天针对 dev 的 79e6b1209f 进行，后者已包含整个 Rodada 29—— 带柔和赤陶色强调的中性黑色主题（AT-283/284）、Card/Chip/Badge/Button （AT-286..288）、移动端外框（AT-316）、会话栏（AT-317）、对话流截断 （AT-319）、审批的修复（AT-296..299、AT-310、AT-318、AT-320）、设置的预算 （AT-321）、PR 和 Containers 的文案（AT-323、AT-324）以及 i18n 的一轮处理 （AT-289、AT-326）。

    截图不在仓库中。每条发现都写明截图的文件名，以便拥有截图文件夹的人打开它； 每条由检查器测得的发现也写明数字。

    产品是如何启动的（以及这不覆盖什么）

    任务要求通过 docker/smoke.sh 并设 SMOKE_KEEP_UP=1 启动生产 compose。这在一个 一次性 compose 项目中尝试过（COMPOSE_PROJECT_NAME=r30visual），并且在此环境中 失败，原因与“之前”记录的相同：出站代理阻止了 dl-cdn.alpinelinux.org（以及 repo.hex.pm/builds.hex.pm），因此 docker/engine/Dockerfile.prod 的第一个 apk add --no-cache build-base git 以 2 退出，没有构建出任何生产镜像。一次性项目已用 down -v 删除。

    因此“之后”运行在与“之前”相同的替代环境上，这是有意为之——不同的栈会让比较测量 的是栈本身：

    • Postgres：容器中的 pgvector/pgvector:pg16，api 的 migration 以及 pnpm seed（seed 在新数据库上干净地运行）。
    • api：从此 checkout 构建的 node dist/main，端口 3000。
    • engine：端口 4000 上对一切都返回 200 的 HTTP stub。没有 Phoenix 通道，没有 engine.* schema。
    • web：端口 5173 上 vite 的开发服务器。
    • 数据：seed 加上与“之前”相同的脚本化填充——一个带对话、brief、业务规则、 Criativo→PO handoff、epic/故事/任务和一个 module_map 的创意会话；第二个带真实 对话流和一个 agent.error 的创意会话；以及分布在 3 个会话中的 4 个待处理 proposed_actions（3 个 terminal，1 个 git_push），格式与之前相同。

    对阅读本页的影响：

    • 会话的 socket 总是失败，因此回合的活动条和代码页的终端从不出现，会话以回退间隔 轮询。
    • GET /workspaces/:id/projects-summary 返回 500，因为 engine.dev_agent_states 不存在——这是 stub 的产物，和“之前”一样。Dashboard 上的 “0 agentes” 不是发现。
    • 数据与“之前”并不完全相同：seed 现在会激活自己的会话，Criativo→PO 的提议在 PO 的 backlog 事件到来时（AT-291/292）已被取代，而最新的会话是咨询式的。当“之前” 的某条发现依赖于已不存在的数据时，它被标为未复核而不是“已修复”。
    • 截图是 fullPage，但大多数界面在内部容器中滚动，所以它们显示的是视口。定向裁剪 （detalhe-*）覆盖了整页截图够不到的部分。

    截图是有节奏的——界面之间 6 s，主题/视口轮次之间 65 s——并记录到零个 429 响应。 “之前”没有控制节奏，所以它的设置页截图部分是在速率限制下拍的；速率限制在下文单独 测量（G1）。

    本页不测量什么

    • 对比度。那是基于 token 的算术，位于 web 的测试套件中 （apps/web/src/lib/contraste.ts）；这里的检查器只看布局。
    • engine 之后的任何东西：实时回合条、终端、dev agent 的在场状态。stub 无法产生它们。
    • 生产构建。开发用的 vite 提供相同的组件和 CSS，但不提供生产的 CSP，也没有 web 镜像前面的 nginx。
