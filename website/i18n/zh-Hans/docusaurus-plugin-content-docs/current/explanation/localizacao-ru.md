# 本地化——俄语（`ru`）

通用规则见[本地化](localizacao.md)。

- **复数：** `one`、`few`、`many` 和 `other`——四种形式，界面在每个复数键中
  都要求这四种（1 → `one`，2–4 → `few`，5–20 → `many`，小数 → `other`）。
- **术语：** 在 pt-BR 中保留英文的术语表词条（*handoff*、*gate*、*runner*）
  在俄语中同样保留英文，使用拉丁字母。
- **不翻译：** Brabo、agent 名称和角色名称、命令、路径、RN/ADR 编号。
  不要把专有名词音译为西里尔字母。
