    idstringrequired
    Example:"01JC4Z0000PROJETO0000000001"
    workspaceIdstringrequired
    Example:"01JC4Z0000WORKSPACE00000001"
    namestringrequired
    Example:"Checkout"
    slugstringrequired

    在 workspace 内唯一。

    Example:"checkout"
    workspaceDirNamestringrequired

    此项目在 PROJECT_WORKSPACES_ROOT 中的物理 workspace 文件夹名称（RN-109）。新项目为 <slug>-<8 id chars>；在此列存在之前创建的项目为原始 UUID。在创建时冻结——之后编辑 slug 不会重新计算它。

    Example:"checkout-3f2b1c8e"
    executionModestringrequired

    命令在哪里执行（RN-169/RN-421——ADR 0072/0104）。container：在 PROJECT_WORKSPACES_ROOT 中托管的文件夹。mounted：workspacePath 中的用户文件夹，位于 BRABO_PROJECTS_BASE 内，通过基目录的 bind-mount 访问（ADR 0141）。runner：由 runner 确认的用户文件夹。mounted 和 runner 都会在 workspaceVerifiedAt 中报告确认。

    Enum:"container""mounted""runner"
    Example:"container"
    workspacePathobject or nullrequired

    用户文件夹的绝对路径——mounted/runner 时填写，始终为 null，在 container 模式下。

    Example:null
    workspaceVerifiedAtobject or nullrequired

    路径在磁盘上被确认的时间。null = 尚未验证。在 runner 中，确认来自 CLI 连接（RN-423）；在 mounted 中，在 Infra 启动容器、文件夹被物化时打上时间戳（RN-501，ADR 0142）。container 从不填写此字段。它记录的是一次确认，绝不是心跳。

    Example:null
    mirrorPathobject or nullrequired

    用户机器上的镜像目标——位于挂载基目录之外、本地代理把工作复制到的文件夹（RN-515，ADR 0147）。null 表示项目没有镜像，这是正常状态，绝不是错误。只有 mounted/runner 可以有。通过 PUT /projects/:projectId/mirror-path 设置；它随每次项目读取一并返回，因此不需要专用端点来获知。该值只经过词法校验——文件夹是否存在由本地代理知道，而不是此 API。

    Example:null
    languagestringrequired

    项目的语言（RN-619）：所有没有人类作者的内容所使用的语言——共享制品（产品简介、业务规则、ADR）以及没有人输入的回合（启动、dev agent、gate、提交信息、PR 正文）。规范的 BCP-47 代码，开放列表。新项目以其创建者的有效回复语言开始（RN-618）。通过 PATCH /projects/:projectId（maintainer）设置。engine 在每个没有人类作者的回合的每次 LLM 调用末尾，以临时系统消息的形式把它发送给模型（RN-622）；在某人的回合中发出的制品仍遵循此人的回复语言。

    Example:"pt-BR"
    createdBystringrequired
    Example:"01JC4Z0000USUARIO0000000001"
    taskBudgetMicrosobject or nullrequired

    每个 dev agent 任务的 token 上限，以微美元计。null 使用领域默认值。

    Example:500000
    maxConsecutiveBlockedobject or nullrequired

    每个 dev agent 的熔断器（Phase 12b——RN-047）：在停到 idle_tripped 之前，连续以阻塞结束的任务数。null 使用领域默认值。

    Example:3
    storyPromotionstringrequired

    谁把 story 提升为 ready（Phase 12c——RN-048）。manual：PO 提议，用户决定。auto：创建时自动提升——自 RN-659 起为新项目的默认值；之前创建的项目保留原有的值。

    Enum:"manual""auto"
