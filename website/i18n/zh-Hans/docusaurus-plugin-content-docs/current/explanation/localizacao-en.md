# 本地化——英语（`en`）

通用规则见[本地化](localizacao.md)。

- **复数：** `one` 和 `other`。pt-BR 的 `_zero` 在英语中没有对应形式。
- **固定术语：** *handoff*、*gate*、*harness*、*runner*、*binding*、
  *lead* 和 *dev agent* 保持原样（它们已经属于术语表）。“Sessão”是
  *session*，“aprovação”是 *approval*，“história”是 *story*，“regra de
  negócio”是 *business rule*。
- **不翻译：** 作为专有名词的 agent 名称（Criativo、
  Arquiteto——术语表在首次出现时用括号给出对应词）、Brabo、命令、RN/ADR 编号。
