# ADR 0085 — Поток ролей как декларативный реестр (fluxo.yml)

## Статус {#status}
Предложен

## Контекст {#contexto}
У продукта три истины о команде агентов в трёх местах:
каталог (`agent-areas.ts`, один источник, FASE 18), контроль
(`docs/gates.yml`, ADR 0054) и ОТНОШЕНИЯ — кто что кому
передаёт, — которые существуют лишь неявно в prompts, use cases и в
истории ADR. Неявное отношение не проверяемо и не измеримо.
Модель команды, спроектированная в авг/2026 (карта рыночных профессий →
агенты), произвела эту третью часть без места, где ей жить, и
аудит против продукта разошёлся в четырёх пунктах именно из-за
её отсутствия.

## Решение {#decisão}
Версионируемый `docs/fluxo.yml`, разделённый по уровням, с контрактами по
ролям: миссия, типизированные входы/выходы (артефакт + источник/адресат +
via), выходной gate со ссылкой на gates.yml, статус
(`active|planned|proposto|em-refinamento`) и объявленные поглощения.
Правила:
- Роль `proposto` ОБЪЯВЛЯЕТ, кто её поглощает сегодня, и объективный критерий
  разделения — целевая оргструктура становится последовательностью активации, а не
  стремлением.
- Роль, ссылающаяся на несуществующий в gates.yml gate, проваливает тест;
  активный gate без роли-владельца проваливает.
- Роль `em-refinamento` сохраняет код нетронутым и выходит из формального потока;
  открытые пункты, создаваемые приостановкой, объявляются в самом файле.
- Отношение со статусом `lacuna` — отслеживаемый backlog, никогда не обещание.

## Рассмотренные альтернативы {#alternativas-consideradas}
- Оставить неявным: отвергнуто — именно отсутствие этой части заставило
  аудит разойтись с продуктом.
- Слить с gates.yml: отвергнуто — контроль и отношение меняются по
  разным причинам (ADR 0054 объявляет замки; этот объявляет контракты).
- Регистрировать только активные роли: отвергнуто — без `proposto` с
  критерием каждая новая возможность заново открывала бы модель с нуля.

## Последствия {#consequências}
- Активация Staff/Platform и предлагаемых gates
  (necessidade-validada, adr-aprovado, implementavel,
  prototipo-validado) становится изменением данных + собственным ADR.
- Psicólogo/Anamnese в refinamento остаются с видимыми открытыми пунктами
  (автор предложения предела RN-086; триггер Staff).
- Таблица триггеров modelo-de-time.md — дорожная карта будущих
  волн: каждый триггер запускает выделение соответствующей роли.
